CULINARY VISUAL TEACHING: EDITORIAL CORRECTIONS
23 October 2026

The review found several general rules that would become misleading if turned into illustrated instructions. This pass corrects the active learning text while retaining the sealed archive, entry slugs, graded mark IDs and Cuisine card IDs.

Changes
- Custard: the tempering step no longer implies a universal cooking endpoint. Starch-free pouring custards and starch-thickened fillings have distinct heating and texture checks. The film prompt no longer claims a spoon measures an exact temperature.
- Braising: browning, liquid level, sauce body and intact or pulled finish depend on the recipe. Tenderness must be checked; elapsed time does not diagnose every fault.
- Blanching: a temporary drop in bubbling is not automatically stewing. Time, texture and purpose work together; prescribed preservation timings still apply.
- Resting: probe placement, measured carryover and process verification replace the unqualified poultry range and fixed rest/temperature rules. A juice pool is not a reliable diagnosis by itself.
- Fryer: the ambiguous baking-soda-or-lid instruction becomes scoped small-pan USFA guidance; commercial fryer response belongs to the kitchen's training and suppression system.
- Service: the track now points to the existing Cuisine allergen-conversation lesson and describes its limits accurately.
- Eggs Owen: menu components remain intact. The general braise is labelled as a teaching model; invented house timings no longer become quiz answers. Its Hussarde illustration is explicitly a comparison.

Implementation
Three source-level corrections are stored as reasoned, sourced lexiconDefinitions in overrides.json. applyLexiconDefinitions validates identity and evidence, preserves unmodified raw inputs, and applies the active definition before technique anchors, drills and search are emitted. Definition corrections deliberately retain established cross-links; this pass does not reclassify their recipe matches.

Both npm run build:data and npm run build:cuisine completed on 23 October 2026. The first passed all derivation gates; the second retained 179 entries, 2,086 cards, 1,562 questions and all existing IDs.
